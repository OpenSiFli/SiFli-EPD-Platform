# 应用运行与生命周期

动态应用包含主模块、可选私有库和资源，由平台安装器登记和装载。动态模块与平台共享 HCPU 地址空间，平台通过模块引用、受管后台服务和存储会话防止仍在运行的代码被提前卸载。

## 从安装到运行

| 阶段 | 行为 | 持有的资源 |
| --- | --- | --- |
| 安装 | 检查 `.sap` 清单、版本、文件记录和内容，写入暂存目录，完成后发布安装。 | 安装事务、对应存储会话、当前文件句柄。 |
| 枚举 | 读取应用清单和图标，发布入口。 | 应用目录信息；仅展示图标不要求常驻全部程序。 |
| 后台启动 | 声明 `background: true` 的应用由服务管理器启动。 | 模块引用、服务记录、可选 worker 与网络订阅。 |
| 页面打开 | 根据应用 ID、安装位置和版本装载主模块，创建页面。 | 页面模块引用、控件、输入监听及页面数据。 |
| 按需任务 | 页面启动文档、网络、媒体等工作。 | 独立服务引用和任务资源；不以页面是否可见判定任务已经结束。 |
| 页面退出 | STOP 撤销页面回调并删除对象，释放页面引用。 | 后台仍有任务时保留对应模块。 |

书架、笔记和 AI 对话当前没有声明安装后常驻后台。它们在有业务需求时创建相应任务；天气声明后台服务。`background: false` 也不代表应用不能在运行期间建立受管 worker。

## 模块装载与验证复用

装载器将应用 ID、根目录、安装版本、文件版本和 TF 卡会话绑定。已驻留模块只有身份一致时才复用；新装载的主模块或私有库执行相应验证。模块加载结束还会复查版本，避免拔卡或更新恰好发生在最后一次读取之后。

私有库不再次完整读取已经验证的主程序。更新、存储变化或文件修改使旧验证失效。SDK 按模块名查找已加载模块，平台另行检查安装位置，防止同名程序来自不同目录时被误复用。

## 受管服务与停止顺序

服务描述符可以声明 worker、网络订阅、UI 分步回调、flush 和停止处理。worker 处理文件与网络等工作，UI 回调只在界面线程操作 LVGL。服务 API 的用法见[后台任务开发](../development/application-lifecycle.md)。

1. 更新、卸载、拔卡或回收请求先阻止新任务进入。
2. 平台要求相关页面退出，向 worker 投递停止事件。
3. worker 取消等待、关闭文件和网络请求，完成必要保存后返回。
4. 平台等待在途调用、回收保护及 UI 清理结束，随后注销网络订阅。
5. 最后释放模块引用。只有引用不再保护任何执行路径时才卸载程序。

超时只结束本次操作或改变状态，不强杀仍在访问模块的线程。收到停止请求以后，旧任务仍然拥有自己的缓冲，任务退出和资源释放必须由明确的所有者完成。

## 异步结果和页面寿命

后台不得保留已经删除的控件地址。页面向任务提供稳定的请求身份，任务发布独立结果；界面再次检查页面和请求版本后消费。旧结果、失败结果和取消结果都要释放自有数据。正文、图片与字体若仍被显示链路借用，则等待该借用结束。

## 安装、数据迁移和恢复

安装包在解包过程中完成记录与内容校验，文件操作检查写入、同步与最终替换结果。更新同一应用需要满足清单版本与数据版本要求。普通安装入口只接受 `.sap`；安装后的应用仍以程序和资源文件目录存放，这属于运行布局。

数据迁移在目标没有既有业务数据且满足安装器条件时执行。迁移失败限制对应应用，不禁用同一存储上的其他应用。卸载保留业务数据，重新安装由应用检查数据版本。缓存可重建，不作为业务数据跨卷迁移。

TF 卡应用在当前插卡会话确认加载后才启用。锁屏时延后加载弹框；拔卡使旧会话失效。具体交接时序见[内存与存储](memory-storage.md)。

## 资源归属速查

| 资源 | 所有者 | 退出时的处理 |
| --- | --- | --- |
| 页面、键盘、定时器、输入监听 | 创建页面 | STOP 时撤销监听和定时器，解除对象引用并删除。 |
| worker、事件、网络订阅 | 受管服务 | 取消业务并等待返回，注销订阅后才删除事件。 |
| 私有库与主模块引用 | 装载器及调用持有者 | 在途调用结束后逐一关闭，不按页面数量推断引用数。 |
| 打开的文件与卡会话 | 文件任务 | 检查会话、关闭句柄，禁止旧会话向新挂载提交。 |
| 计算会话与共享缓冲 | 组件客户端 | 取消、等待 STEP 返回、CLOSE 成功后释放。 |
| 可恢复后台数据 | 应用服务 | flush 完成后参与回收，恢复时从持久化记录重建。 |

实现入口：源码：`src/ui/platform/app_module.c`、源码：`src/services/app_service.c`、安装包校验（源码：`src/ui/platform/app_package.c`）。
