# 设备使用手册

设备通过桌面打开应用，通过设置管理连接、显示、声音、存储和时间。书架、天气、AI 对话、内容看板、日历、图库、音乐、笔记和单词的操作见[应用使用手册](application-guide.md)。应用只有安装并成功加载后才显示入口。

## 开关机、锁屏和返回

| 操作 | 步骤 | 结果 |
| --- | --- | --- |
| 开机 | 按实体电源键启动设备，等待桌面出现。 | 读取已经保存的设置和内部应用。全新配置默认关闭前光。 |
| 锁屏 | 设备工作时短按电源键。 | 出现锁屏，原来的应用状态保留。 |
| 解锁 | 长按屏幕上的解锁按钮约一秒。 | 回到原应用或桌面。 |
| 从墙纸休眠唤醒 | 短按电源键，再按锁屏页面要求解锁。 | 恢复操作；无线连接按原设置恢复。 |
| 关机 | 长按电源键打开电源菜单，选择关机。 | 保存完成后全刷墙纸，关闭前光并关机。 |
| 返回 | 点击页面左上角返回按钮。 | 返回上一级页面。未结束的音乐或录音按各应用规则继续。 |

## 无线连接和网页

1. 打开“设置”，进入无线连接页面，再进入“WLAN”。
2. 开启 WLAN，扫描并选择网络，输入密码后连接。保存的网络可按自动连接设置重新连接。
3. 需要连接手机或耳机时，进入同一设置分类下的“蓝牙”，开启蓝牙并选择设备连接。手机是否提供蓝牙网络共享，由手机设置决定；普通蓝牙连接不要求网络共享开启。
4. 需要网页管理时，在设备网页入口查看地址，使用同一网络上的电脑或手机浏览器打开该地址。首次使用按页面提示建立管理账号并登录。

设备自动优先使用可用 WLAN；WLAN 不可用且蓝牙网络共享已经连接时，使用蓝牙网络。蓝牙耳机连接不提供网络。状态页的 IP 地址表示本地连接信息，天气、AI 等应用仍可能因外网或服务配置而无法访问。

需要由设备提供热点时，在网页连接相关入口开启热点，按屏幕显示的名称和密码连接，再打开设备地址。热点用于访问设备，不替手机或电脑提供互联网转发。

网页可管理文件、应用、阅读字体、平台 AI、语音、时间和账号。设置按顶部页签切换，当前页签下显示对应内容。网页使用和初始账号流程详见[设备与网页管理](../getting-started/device-management.md)。

## USB 传文件

1. 插入 TF 卡，用 USB 连接电脑。
2. 进入“设置”的无线连接分类，打开“USB”，开启“TF 卡读卡器”。等待电脑出现磁盘。
3. 在电脑磁盘中复制书籍、图片、音乐、字体或 `.sap` 安装包。传输期间设备上的 TF 卡文件暂不可用。
4. 文件复制结束后，在电脑弹出磁盘，再关闭设备的读卡器开关。等待设备重新识别 TF 卡。
5. 出现卡上应用加载提示时，按需选择加载。锁屏期间该提示会延后到解锁后显示。

## 显示、声音和睡眠

| 功能 | 操作入口与方法 | 可观察结果 |
| --- | --- | --- |
| 前光 | 在显示设置中调整前光开关、亮度或模式。 | 亮度改变，关闭后仍可借助环境光阅读。 |
| 界面大小 | 在显示设置中选择界面缩放档位。 | 系统文字与控件按选择调整。 |
| 刷新方式 | 在显示设置中选择普通刷新、右到左（黑白）或左到右（黑白）。 | 黑白模式按方向分条带刷新；切换时先完整刷新一次。选择会保存，旧设置默认使用普通刷新。 |
| 全刷 | 调整全刷间隔；阅读中也可选择“立即全刷”。 | 屏幕进行完整刷新以清理残影。 |
| 声音 | 进入声音设置，调整可用音量和触摸提示音。 | 后续播放和触摸提示按对应设置工作。 |
| 墙纸 | 进入锁屏与墙纸设置，选择可用墙纸。 | 系统休眠和关机时全刷显示该墙纸。 |
| 屏幕睡眠 | 在锁屏与墙纸设置中选择等待时间。 | 无操作达到时间后锁屏。 |
| 系统休眠 | 在同一页面选择等待时间。 | 锁屏后继续无操作，并且没有播放、录音或传输等活动时，进入墙纸休眠。 |

持续播放、录音、读卡器工作及网页请求可能延后系统休眠。控制中心显示正在进行的媒体任务，可操作播放或暂停；通知中心查看已经产生的应用通知。

## 字体和文字排版

在阅读菜单中进入“排版”调整字体、字号、字重、行距和页边距。新设置会在菜单仍打开时应用到正文。字体选择为全局阅读设置，切换书籍或退出重开仍使用同一选择。

导入外置字体时，把 TTF 文件复制到 TF 卡，在阅读字体管理页面选择“安装字体”，选择文件及目标存储。安装完成后选择该字体。删除字体在字体管理页面完成；内置字体由固件提供。字体所在 TF 卡不可用时，该外置字体也无法读取，恢复卡后重新检查字体状态。

## 应用和文件

| 操作 | 步骤 | 结果 |
| --- | --- | --- |
| 安装应用 | 进入“应用管理 → 应用安装”，找到 `.sap`，选择内部存储或 TF 卡，确认安装。 | 成功后出现应用入口。 |
| 更新应用 | 在相同入口选择该应用更高版本的 `.sap`。 | 沿用原安装位置，完成后运行新版。 |
| 卸载应用 | 进入“应用管理 → 应用卸载”，选择应用并确认。 | 程序和缓存移除，业务数据按应用存储规则保留。 |
| 加载 TF 应用 | 插卡后确认加载，或使用应用管理中的加载卡上应用入口。 | 当前卡上已安装且可用的应用出现在桌面。 |
| 打开文件 | 在文件管理中进入文件所在目录，点击支持的文件。 | 由已安装、支持该类型的应用打开。 |
| 查看空间 | 在更多设置中打开存储管理或内存使用。 | 查看文件存储与运行内存的各自状态。 |

`.sap` 是安装包。安装后程序与资源以目录保存，正常使用无需手动拆包。笔记的数据固定保存在 TF 卡的 `Notes` 目录，日历提醒保存在设备内部；它们的程序安装位置不改变这一规则。

## 时间、语言和服务配置

在更多设置的日期与时间页面开启自动设置时间，连接可用网络后等待更新时间；关闭自动设置后可以手工修改。时区和 12/24 小时制独立选择。时间显示占位符时，尚未取得有效时间。

语言页面可以切换中文和英文。平台 AI 与语音服务在对应设置页管理服务、模型及应用授权，完整字段说明见 [AI 服务](../services/ai-services.md)和[语音服务](../services/speech-services.md)。天气另使用自己的服务配置。

## 重置与设备信息

在更多设置中进入“重置”，选择需要的操作。TF 卡的 `.epd` 目录保存平台统一管理的应用程序、业务数据和缓存，这些内容称为受管应用及数据。该目录以外的书籍、图片、音乐、安装包和 `Notes` 笔记目录属于卡上的普通文件。更多术语见[术语与缩写](../getting-started/glossary.md#设备使用中的术语)。

| 选项 | 操作结果 |
| --- | --- |
| 重置 WLAN 和蓝牙 | 清除已保存的 WLAN 网络和蓝牙配对，恢复无线连接设置。 |
| 格式化 TF 卡 | 清空整张 TF 卡，包括 `.epd`、`Notes` 和其他普通文件；内部存储不受此操作影响。 |
| 恢复出厂设置 | 清空内部存储中的用户设置、已安装应用及其数据。确认清理 TF 卡时，再删除该卡的 `.epd` 目录内容；TF 卡上的 `Notes`、书籍、图片和音乐等普通文件保留。 |

重置过程中如果提示等待原 TF 卡，插回原卡后选择重试；页面提供“保留 TF 卡并结束重置”时，也可以按该选项结束未完成的卡清理。已完成的内部重置不会撤销。

关于设备页面提供版本及设备信息；未启用的系统更新和使用手册入口没有可执行流程。
