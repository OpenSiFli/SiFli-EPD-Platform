# 术语与缩写

## 设备使用中的术语

| 术语 | 含义 |
| --- | --- |
| 墨水屏、EPD | 通过刷新改变画面、静止时可以保留显示内容的电子纸屏幕。完整刷新称为“全刷”，用于清理残影。 |
| 前光 | 从屏幕前方照亮显示区域的灯光。关闭前光后，仍可借助环境光阅读。 |
| TF 卡 | 设备使用的可移除 microSD 存储卡，设备文件路径以 `/sdcard/` 开头。 |
| 内部存储 | 用于保存应用、设置和数据的设备内置文件系统，路径以 `/flash/` 开头。 |
| 动态应用、`.sap` | 动态应用可以独立安装和更新；`.sap` 是包含程序、清单及资源的安装包。安装后文件以目录存放。 |
| 受管应用及数据 | 平台安装器与存储服务统一管理的应用文件。TF 卡上位于 `.epd` 目录，具体删除范围见[重置说明](../user/user-guide.md#重置与设备信息)。 |
| 普通文件 | TF 卡 `.epd` 目录之外的文件，例如书籍、图片、音乐和 `Notes` 中的笔记。应用也可以按自身规则使用这些目录。 |
| 读卡器交接 | 将 TF 卡的访问权从设备文件系统交给电脑，或从电脑交回设备。电脑使用读卡器期间，设备暂停访问卡内文件。 |
| 屏幕睡眠、系统休眠 | 屏幕睡眠指无操作后进入锁屏；系统休眠还会在保存和外设准备完成后显示墙纸并降低功耗。两项等待时间分别设置。 |
| WLAN、Wi-Fi | 无线局域网连接。设备连接路由器后使用其网络；能取得本地 IP 地址不代表外部服务一定可访问。 |
| PAN | 蓝牙个人区域网络。本平台用它接入手机提供的蓝牙网络共享；耳机或普通蓝牙连接不等于已建立 PAN 网络。 |

## 开发中的术语

| 术语 | 含义 |
| --- | --- |
| HCPU | 负责系统界面、文件访问和设备服务的主处理核。界面与后台工作由不同线程调度。 |
| ACPU | 执行已注册计算组件的协处理核，本平台把文档转换、字体、排版和页面合成等任务交给它处理。 |
| LCPU | 低功耗处理核。蓝牙协议及核的低功耗调度由 SDK 管理，平台通过蓝牙接口提出扫描、连接和停止等请求。 |
| RT-Thread、LVGL、app_fwk | RT-Thread 提供线程与设备等系统能力；LVGL 绘制界面；SDK 的 app_fwk 管理应用与页面的启动、暂停和退出。 |
| 受管后台服务 | 通过平台服务管理器登记的后台工作。管理器协调线程、网络事件、保存、休眠和模块引用；页面退出后服务可以按声明继续运行。 |
| `svc` | 设备串口控制台中查询服务或向服务发送命令的入口。应用可支持的子命令由各服务实现决定。 |
| SRAM、PSRAM、Flash | SRAM 是片内运行内存；PSRAM 是容量较大的扩展运行内存；Flash 在掉电后仍保存固件和文件。Flash 中的文件需要读入运行内存后才能作为普通缓冲区使用。 |
| ABI | 程序之间传递参数、调用函数及解释公共数据结构的二进制约定。固件和动态应用必须使用兼容的 ABI。 |
| ELF、`.so`、`.so.nostrip` | ELF 是可执行和链接文件格式；动态应用的 `.so` 是共享模块；`.so.nostrip` 保留调试信息，用于解释故障地址。 |
| TF 卡会话 | 一次有效挂载的身份标识。拔卡、换卡或交接后，旧任务不能继续使用原会话读写。 |
| 页面图像缓存 | 已完成正文、字形和合成的页面像素，可直接提交显示。只有排版结果时，仍可能需要准备字形和合成图像。 |
| Anyka 3A | 项目接入的音频前处理组件，用于回声消除、降噪和自动增益等处理。当前板级准入配置尚未开放该组件执行。 |
| Gerrit、Change、PS | Gerrit 是代码评审系统；Change 是一项评审；PS 是同一评审的补丁集版本，例如 PS3 表示第 3 版。 |
| Gerrit `NEW` | 评审仍开放，尚未合入或放弃；这个状态下可以已经存在评审意见。 |

接口细节见[应用接口参考](../reference/api-reference.md)，各处理核和服务的数据流见[系统架构总览](../architecture/architecture.md)。
