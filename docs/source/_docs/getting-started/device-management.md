# 设备与网页管理

设备网页提供文件传输、设备信息、应用安装和设置。浏览器与设备连接同一 Wi-Fi，或连接设备创建的热点后，使用设备显示的网站地址访问。

## 连接网页

在设备的“设置 → 无线与连接”中连接 Wi-Fi。取得局域网地址后，网页服务自动开启；打开设备的“无线传输”及“网页后台”页面，查看当前模式、网站地址或扫码打开网页。局域网地址由网络分配，重新连接后可能变化。

没有路由器时，在“无线传输”中开启热点，用电脑或手机连接页面显示的网络名称和连接密码，再访问 `http://192.168.169.1/`。热点用于访问设备本地网页，不提供互联网转发。访问云端 AI、语音和在线内容时，设备需要可用的上行网络。

网页打不开时，先核对设备页面显示的模式与地址，再确认浏览器所在设备与墨水屏之间可以互访。热点开关操作完成后等待服务状态变为就绪再刷新。

## 创建和管理账户

首次使用时，在设备“无线传输 → 网页账户管理”中选择“开启首次账户初始化”。设备显示一次性初始化码，设置窗口持续 5 分钟。

1. 在浏览器刷新登录状态，进入首个账户设置表单。
2. 填写用户名、密码、确认密码和设备本次显示的初始化码。
3. 提交成功后使用该账户进入管理页面。

用户名为 3～32 个英文字母、数字、下划线、点或连字符；密码长度为 8～64 个 UTF-8 字节。热点和 Wi-Fi 局域网使用同一套网页账户，热点连接密码另行管理。

设备的账户管理页面可查看用户名、添加账户、修改密码和删除账户，最多保存五个账户，已保存密码不回显。删除账户会使该账户的现有登录失效；删除最后一个账户后，再次使用网页需要重新开启初始化。浏览器使用“退出登录”结束当前会话。

## 传输文件

网页“文件”页浏览 TF 卡目录，提供新建文件夹、上传、下载和删除操作。上传后等待设备保存完成，再刷新目录确认文件。没有可用 TF 卡或 TF 卡正交给 USB 读卡器时，文件操作不可用。

书籍、音乐和图片上传到应用能够浏览的 TF 卡目录后，从对应应用打开。文件管理和应用安装使用不同入口；安装包上传到文件目录后仍需执行安装。

## 安装应用

在网页“设置”中的应用安装区域选择电脑上的 `.sap`，指定内部存储或 TF 卡作为安装目标，然后执行上传并安装。上传进度达到 100% 后，设备还需要完成校验和安装，最终以任务结果为准。

设备端安装入口为“设置 → 应用管理 → 应用安装”。浏览 TF 卡任意可访问目录，选择 `.sap` 及目标卷。更新沿用原安装卷，版本规则见[应用清单](../reference/app-manifest.md)。成功后从桌面打开应用；TF 卡应用需在设备上确认加载。

在桌面长按应用图标可以进入应用设置、固定到程序坞或卸载。卸载会删除应用程序和缓存，业务数据保留。内置系统入口由固件提供，管理方式与动态应用不同。

## 字体和服务设置

网页“设置 → 阅读字体”可上传静态 TrueType `.ttf`，选择内部存储或 TF 卡，并在任务完成后应用或删除字体。单文件最大 32 MiB；实际可用空间仍由设备检查。阅读字体用于正文，桌面和菜单使用平台界面字体。

网页“设置 → 平台 AI”可编辑服务、协议、端点、密钥、模型、默认服务和应用访问授权。网页“设置 → 语音服务”可配置识别与朗读账号、默认服务及语音参数。保存请求受理后等待任务完成，再进行一次实际调用，见 [AI 首次使用](../services/ai-services.md#首次配置与调用)和[语音首次使用](../services/speech-services.md#首次配置与调用)。

网页其他设置按分类展示显示与亮度、锁屏、声音、网络等当前固件可用的控制项。提交后以设备返回状态更新页面；设备信息页提供当前设备和存储状态。

## USB 读卡器与 TF 卡应用

在“设置 → 无线与连接 → USB → TF 卡读卡器”开启共享前，平台停止使用 TF 卡的应用和任务、释放文件，再把 TF 卡交给电脑。内部文件系统继续由设备使用。

电脑文件操作结束后弹出磁盘，在设备上关闭 TF 卡读卡器。设备重新挂载 TF 卡；出现加载应用提示时选择加载，或通过应用管理启动加载。应用入口出现后即可运行。普通文件可以访问与卡内应用已经加载是两个独立状态。

拔卡、再次插卡和 USB 交接会改变卡会话。开发时的取消和文件释放要求见[应用存储](../development/application-storage.md#文件访问与-tf-卡会话)。
