# SAP 格式

`.sap` 是顺序存放文件的单一归档。当前版本为 1，所有整数采用小端字节序，文件内容不压缩。生成实现为 源码：`tools/package_app.py`，设备读取实现位于 源码：`src/ui/platform/app_sap.c`。

## 归档头

固定 32 字节，对应 Python `struct` 格式 `<8sIIQQ`。

| 偏移 | 长度 | 字段 | 值 |
| --- | --- | --- | --- |
| 0 | 8 | magic | `SIFLSAP` 后接一个零字节 |
| 8 | 4 | version | 1 |
| 12 | 4 | file_count | 文件记录数，包含两个元数据文件 |
| 16 | 8 | total_bytes | 整个归档的字节数，包含头、记录、路径及内容 |
| 24 | 8 | reserved | 0 |

## 文件记录

每条记录由 48 字节固定头、UTF-8 路径和文件原始内容组成，三部分连续存放，没有填充。固定头对应 `<HHQ32sI`。

| 偏移 | 长度 | 字段 | 值 |
| --- | --- | --- | --- |
| 0 | 2 | path_bytes | 后续路径的 UTF-8 字节数，不含结尾零 |
| 2 | 2 | flags | 0 |
| 4 | 8 | file_bytes | 文件内容字节数 |
| 12 | 32 | sha256 | 文件内容 SHA-256 的二进制值 |
| 44 | 4 | reserved | 0 |

记录顺序固定为 `app.json`、`files.sha256`，随后是其余文件按路径 UTF-8 字节排序的记录。第一条包含[最终应用清单](app-manifest.md#构建生成字段)，第二条包含文件索引。

## 文件索引

`files.sha256` 每行包含 64 位小写十六进制 SHA-256、两个 ASCII 空格、相对路径和 LF 换行。它覆盖主模块、私有库、图标和资源，不包含自身和 `app.json`。路径唯一，按 UTF-8 字节排序。

清单的 `files_sha256` 是整个索引文件的摘要。归档记录还携带每个文件的摘要，包括两个元数据文件。解包时核对记录摘要，再验证清单、索引与实际文件集合的一致性。

## 长度与路径约束

归档最多 1 GiB、8192 条文件记录，`app.json` 最多 65536 字节。包内路径为相对路径，最多 159 个 UTF-8 字节、八层，使用 `/` 分隔。

路径不含空组件、`.`、`..`、控制字符、反斜线及 `:<>"|?*`，每个组件末尾不能是空格或点。归档只记录普通文件；目录由路径隐含，构建输入中的符号链接及 Windows 重解析点被拒绝。

总长度、记录数、文件索引及每个文件长度均须准确匹配。格式容量上限不代表设备有等量可安装空间，目标卷还需容纳安装暂存和现有文件。安装提交过程见[更新事务](../development/application-lifecycle.md#更新事务)。
