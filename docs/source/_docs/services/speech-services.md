# 语音服务

系统统一管理语音账号、识别、朗读和音频使用权。普通原生输入框使用系统语音入口；动态应用也可通过 `epd_speech.h` 提交识别或朗读请求。账号和凭证由平台保存。接口定义位于 `src/platform/epd_speech.h`。

## 服务和配置

设置入口为“更多设置 → 语音服务”。语音输入可选腾讯或阿里；文字朗读可选腾讯、阿里或豆包。两个默认项独立保存，初次使用均未选定。服务账号配置保存在内部存储的 `/flash/config/speech-services.json`；普通页面只显示配置状态、音色与语速，不回显凭证。

系统使用腾讯实时识别 V2、腾讯流式合成、阿里 Fun-ASR、阿里 CosyVoice 和豆包语音合成模型 2.0。阿里使用百炼 API Key，豆包使用语音服务 API Key。腾讯需 AppID、SecretId、SecretKey。

从[配置模板](../../speech-services.example.json)填写需要的账号并删除不用的账号记录。阿里还需填写北京地域的 `workspace`；`asr`、`tts` 分别选择 `tencent`、`ali`、`doubao` 或 `none`，其中豆包只用于朗读。将 JSON 文件放入 TF 卡，在语音服务页面选择“导入配置文件”。空凭证和不支持的音色不会被保存。账号也可以在对应厂商页面中编辑。

变更默认服务、音色、语速或凭证只影响新会话。已有会话继续使用开始时的快照；删除或禁用账号会停止该账号的会话，包括暂停中的朗读。恢复出厂数据删除语音账号，重置无线连接不删除语音账号。

## 首次配置与调用

也可以在[设备网页](../getting-started/device-management.md)的“设置 → 语音服务”填写上述账号。保存后等待任务完成，分别为语音输入和文字朗读选择默认供应商，确认所选供应商的账号已启用且具备对应能力。

测试识别时，打开一个普通文字输入框，点击系统键盘或导航条上的麦克风，说一句短话，再停止录音。确定文字应插入输入框。测试朗读时，在 AI 对话中对一条短回答选择朗读，检查是否播放到句末；自动朗读偏好由 AI 对话应用单独设置。

开始会话失败时检查是否设置默认服务、账号是否启用、当前是否有冲突的录音或播放。已经开始后失败时读取事件中的错误阶段、原始错误码及请求 ID，分别检查网络、凭证、供应商能力和音频输出。配置保存成功不会自动向云端发送合成或识别请求。

## 系统语音输入

普通原生 `lv_textarea` 由系统自动跟踪输入目标，触摸选中的输入框或当前可见 `lv_keyboard` 绑定的输入框无需应用另行注册识别逻辑。点击导航条最右侧的麦克风后，系统打开语音面板；存在有效输入目标时自动开始录音。没有输入框，或输入框处于密码模式、禁用状态、设置了允许字符限制时，不开始录音；目标还必须属于当前页面、可见且可编辑。

使用平台键盘时，配置须为 `EPD_KEYBOARD_TEXT` 且启用 `voice`。正在编辑拼音时，先选字提交或清除拼音，再进入语音输入。键盘接入见[平台键盘](../development/touch-ui.md#平台键盘)。

识别中的临时草稿只显示在面板中。每段确定文字（final）通过输入框原生插入接口写入当前光标位置，触发 `LV_EVENT_VALUE_CHANGED`，由应用原有回调同步业务内容；系统语音输入不自动发送消息。

| 面板控件 | 行为 |
|---|---|
| 停止 | 结束采集，等待识别收尾并插入确定文字，面板保持打开 |
| × | 取消当前识别并关闭面板，丢弃未确定草稿，保留已经插入的确定文字 |
| 键盘 | 正常结束识别，完成收尾后关闭面板，回到原键盘 |

跨页面、锁屏或存储交接时取消系统语音输入；目标删除、失效或更换后，旧会话的迟到结果不会写入其他输入框。单次录音上限为 10 分钟，到时正常收尾，不自动开始下一次录音。AI 聊天输入框复用系统语音输入，朗读由应用自己的会话和自动朗读偏好控制。


## 应用接口

应用先导出 `epd_background_t` 描述符，由平台注册受管服务，将该服务作为 `owner`。平台保留服务与模块引用，应用停止后取消语音并等待清理完成。页面返回桌面后，仍运行的后台服务继续持有模块引用。

```c
#include "platform/epd_speech.h"

epd_speech_request_t request = {
    .struct_size = sizeof(request),
    .version = EPD_SPEECH_VERSION,
    .language = EPD_SPEECH_ZH_EN,
    .background = true,
    .title = "朗读"
};
epd_speech_session_t session;
epd_speech_error_t error = epd_speech_start(owner, EPD_SPEECH_TTS,
                                          &request, &session);
```

`epd_speech_append()` 返回已经复制的完整 UTF-8 前缀长度。返回零表示暂时没有空间；应用保留并稍后重试剩余文字，不在 GUI 或 AI 接收回调中等待。负数是错误码。全部文字接受后调用 `epd_speech_finish()`，会话随后只处理已经接受的文字。

`epd_speech_pause()`、`resume()` 和 `stop()` 是异步控制。暂停关闭本地输出，保留音频缓存和提交位置；继续先重新取得音频使用权，不重复合成已有音频。暂停后若用户另行播放音乐，只有再次明确继续朗读才会暂停当前音乐。重新取得使用权失败时仍保留暂停会话，状态事件的 `snapshot.error` 给出原因，允许稍后重试；终态事件表示会话已经结束。停止释放缓存，旧句柄不能恢复。控制中心提供暂停和继续；停止能力仍由服务接口及具体应用按需要使用。

开始识别使用同一个接口的 `EPD_SPEECH_ASR`。`finish()` 正常结束采集并等待最终文字；`cancel()` 丢弃未确定草稿，保留已交付的确定结果。每次最多 10 分钟，超过时限正常收尾，不自动接续另一条付费请求。

每个所有者仅设一个事件消费者，循环调用 `epd_speech_poll()`，处理后调用 `epd_speech_event_release()`。事件文字只在释放前有效。草稿按 `session`、`sentence` 和 `revision` 更新，不能把每次修订重复追加；确定文字顺序交付。编辑框关闭或更换输入对象时取消原识别，并检查会话身份，迟到结果不得写入新输入框。

系统语音面板复用语音输入绑定接口（源码：`modules/common/input/speech_input.h`），由常驻服务消费识别事件并管理输入目标有效期、草稿修订和确定文字。自定义编辑器也可在应用自己的事件消费者中使用该组件，并把业务状态同步给编辑控件。`background` 是用途元数据；自建会话的页面退出策略由应用明确执行，系统输入在页面退出时取消，朗读可继续在后台运行。

开始操作成功只表示请求已接受，实际录音、播放、暂停与终态以事件或快照为准。快照中的 `submitted_samples` 是交给输出路径的源 PCM 采样数，不是硬件实际播放计数。错误事件保留阶段、原始错误码及请求 ID，不包含密钥、签名 URL 或正文。

## 调度与资源

识别和朗读各最多一个会话。录音优先，先确认朗读输出已关闭；录音期间新建或继续朗读返回忙。已有音乐通过媒体会话暂停确认及用户意图序号决定是否恢复。

朗读按标点选择句子或分句边界。每个单元最多 512 个 Unicode 字符，不能找到合适边界时报告文字过长。文本总预算 16 KiB，两个 PCM 槽共 4 MiB；队列满时返回暂时无法继续追加的状态，调用方稍后重试。在途音频保持有效。

活动采集、网络请求及播放持有产品休眠锁；暂停时输出和在途网络任务均关闭后释放。暂停缓存只保留在内存中，不提供关机、重启或掉电后的续播。

EPD 板当前使用 SDK 原生语音输入。`speech_audio` 通过 `audio_open2()` 采集 PDM1 的 16 kHz、16 位双声道 PCM，每次打开后设置 12 dB 增益并丢弃前 200 ms 预热数据。处理线程默认抽取 MIC1 左声道的原始 PCM，作为 16 kHz、16 位单声道输入交给语音识别（ASR），不做双麦增强。

当前 `EPD_SPEECH_USE_ANYKA=0`，板型计算配置中 Anyka 的 `allow_unvalidated=false`、`validated=false`。可选 Anyka 适配保留，但当前不初始化、不运行。

板级配置将 MIC1 映射为左声道、MIC2 映射为右声道，配置中的坐标间距约为 36.26 mm。双麦坐标、手持距离及固定目标参数供 Anyka 适配使用，不参与当前原始 PCM 输入。参数见板级配置（源码：`boards/sf32lb57-epd-gyd7n6/bsp_speech_profile.h`）。

网络统一使用平台当前上行接口，应用不区分 WLAN 与蓝牙 PAN。厂商已接受的文字不会自动重试或切换供应商。云端会话需要平台选定的 WLAN STA 或 PAN 上行链路。

## 源码入口

| 文件 | 职责 |
|---|---|
| `src/platform/epd_speech.h` | 应用契约与事件所有权 |
| `src/services/speech/speech_core.c` | 会话、命令、事件、模块引用 |
| `src/services/speech/speech_engines.c` | 识别供数、朗读预取与独立音频供数 |
| `src/services/speech/speech_audio.c` | SDK 双声道采集、MIC1 原始 PCM 抽取和受控 PCM 输出 |
| `src/services/speech/speech_media.c` | 媒体交接、提示音抑制和条件恢复 |
| `src/services/speech/providers/` | 五项厂商协议与安全 WebSocket |
| `src/services/speech/speech_settings.c` | 配置工作线程和原子提交 |
| `src/ui/apps/ui_speech_settings.c` | 系统语音设置 |
| `src/ui/ui_voice_input.c`、`src/ui/ui_shell.c` | 原生输入框自动绑定、导航麦克风入口、语音面板与页面生命周期交接 |
| `modules/ai_demo/` | 复用系统语音输入，保留手动朗读和应用自己的自动朗读偏好 |
| `modules/common/input/` | 系统面板与自定义编辑器共用的输入目标绑定、草稿修订与确定文字交付 |
