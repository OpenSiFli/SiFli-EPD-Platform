# 应用使用手册

本手册按应用说明日常操作。设备连接、安装和系统设置见[设备使用手册](user-guide.md)。应用实际入口取决于已安装的应用包。

## 书架

| 功能 | 操作步骤 | 结果 |
| --- | --- | --- |
| 打开书籍 | 将 TXT、EPUB、Markdown 或支持的 MOBI 放入可访问存储，在书架选择书籍；也可从文件管理打开。 | 读取正文并恢复上次阅读位置。有有效元数据的书籍显示实际书名和封面。 |
| 翻页 | 在正文向左滑动；需要回看时向右滑动。 | 向左翻到后页，向右翻到前页。 |
| 阅读菜单 | 点击正文菜单区域打开阅读菜单。 | 查看当前章节、进度和阅读选项。 |
| 章节与跳转 | 在目录选择章节，或在进度页面选择有效目标。 | 显示对应位置；远距离目标可能需要准备。 |
| 排版 | 打开“排版”，调整字体、字号、字重、行距或页边距。 | 菜单保持打开时正文更新；新字体沿用到其他书籍。 |
| 显示 | 打开“显示”，调整前光、全刷间隔、触摸翻页和睡眠设置。 | 选项立即进入对应系统设置或生效。 |
| 注释 | 点击正文中的注释引用。 | 在引用附近显示注释；长内容可滚动，点击外部关闭。 |
| AI 解读 | 在阅读菜单打开 AI 解读，选择已授权服务，发送问题或使用摘要等快捷提问。 | 将当前页文字作为上下文得到回答；纯图片或无可提取文字的页面会提示。 |
| 退出重开 | 返回书架，再打开同一本书。 | 使用保存的位置和当前全局字体继续阅读。 |

书籍缺少封面或元数据时使用默认封面和可用名称。加密、损坏或不支持的文件会显示失败信息。正文准备和完整目录可能分阶段完成，目录尚未就绪时可继续阅读已经显示的正文。

## 天气

1. 复制[配置样例 `qweather.example.json`](../../qweather.example.json)，将副本改名为 `qweather.json`，填入天气服务的 `api_key` 和 `api_host`，再把文件放到 TF 卡根目录。设备读取路径为 `/sdcard/qweather.json`。
2. 在应用管理的应用设置中打开天气设置，选择从 TF 卡导入配置。
3. 按界面指引取得城市 ID，输入并确认城市；已有历史城市可以从查询历史选择。
4. 打开天气，点击刷新，查看实时天气、未来预报、空气质量及各项更新时间。

部分数据请求失败时，成功取得的数据仍可显示，页面提示部分更新。未联网时可以保留上次成功数据；判断是否最新需查看更新时间。服务凭据无效时重新配置，城市错误时重新选择城市。

## AI 对话

先在平台 AI 设置中配置文本服务和模型，并为 AI 对话授权。打开应用，选择模型，输入文字或使用语音输入后发送。回复逐步显示；需要结束生成时点击停止。

联网搜索在模型和服务支持时使用。搜索结果中的来源可以打开来源信息及二维码。朗读按钮播放回复，顶部自动朗读开关控制后续回复是否自动播放；语音服务需先配置。

会话历史是独立页面，可重新打开、重命名或删除会话。新对话按钮建立空会话。发送失败时，消息旁显示简短提示和重试入口；用户输入保留，界面不展示 HTTP、内部阶段或长错误码。更换服务配置导致旧会话不适用时，新建对话使用当前模型。

## 内容看板

打开内容看板，查看页面标题、文字卡片和平台摘要。卡片内容由模板决定，天气摘要不可用时显示模板中的空状态，其余固定文字仍显示。

需要改内容时，按[内容看板模板](../development/board-templates.md)准备 `layout.json`，保存到该应用的用户配置目录，退出再打开看板。模板支持文字、列数、卡片高度和跨列布局，当前没有在设备上直接拖拽设计卡片的界面。

## 日历

| 功能 | 操作步骤 | 结果 |
| --- | --- | --- |
| 浏览日期 | 切换年、月、周、日视图，选择日期或使用日期跳转。 | 当前日期和事项随选择变化。 |
| 新建事项 | 新建日程，填写标题、日期、时间、位置和备注，保存。 | 对应日期出现该事项。 |
| 生日、纪念日、倒数日 | 选择相应事项类型，填写日期及需要的重复规则。 | 按类型显示日期关系或倒数信息。 |
| 编辑和复制 | 打开已有事项，修改或复制后保存。 | 编辑更新原事项，复制产生独立事项。 |
| 重复与提醒 | 设置支持的每日、每周、每月或每年规则及提醒。 | 事项在规则匹配的日期出现，提醒到时进入系统通知。 |
| 搜索与日期计算 | 使用事项搜索或日期计算功能。 | 返回匹配事项或计算结果。 |
| 导入 | 选择 `.calbak` 或支持的 `.ics` 文件，查看预览，选择新增或更新重复项。 | 按确认内容合并记录。 |
| 导出 | 在导出入口选择备份或日历格式。 | 文件保存到界面指定的导出位置。 |

日历业务记录保存在内部存储，退出应用后提醒仍由系统服务处理。锁屏提醒不会打开普通事项弹框。支持公历 1901～2099 年；当前未内置法定节假日和调休表。复杂 ICS 时区、COUNT 等不支持规则会明确提示，完整格式范围见日历组件说明（源码：`modules/calendr/README.md`）。

## 图库

打开图库，选择内部存储或 TF 卡，进入图片目录。使用列表翻页浏览，点击 PNG 或 JPEG 查看。返回后继续浏览原目录。文件读取或解码失败时显示对应提示，返回列表可选择其他图片；移除存储后旧图片不再继续读取。

## 音乐

| 功能 | 操作步骤 | 结果 |
| --- | --- | --- |
| 选择歌曲 | 在“文件夹”选择存储并进入目录，点击 MP3、WAV 或 FLAC。 | 开始播放，目录位置显示完整层级。 |
| 基本控制 | 使用播放、暂停、上一首、下一首，调整播放位置。 | 播放状态与进度变化。 |
| 播放模式 | 选择顺序、列表循环、单曲循环或随机。 | 后续曲目按所选模式播放。 |
| 队列 | 把歌曲加入队列或设为下一首；在当前队列调整顺序、移除或清空。 | 后续播放顺序按队列变化。 |
| 收藏 | 对歌曲添加或取消收藏，进入收藏页。 | 收藏列表同步变化。 |
| 播放列表 | 保存当前队列为命名列表，或导入 M3U8。 | 可从播放列表再次使用。 |
| 定时停止 | 选择 15、30、60 分钟或本曲结束。 | 到达条件后停止播放。 |
| 后台播放 | 返回桌面或锁屏，通过控制中心操作媒体。 | 播放任务继续，控制中心反映当前任务。 |
| 蓝牙输出 | 先连接支持媒体播放的蓝牙设备，再播放并调整音量。 | 声音通过所选输出播放。当前 SDK 音量适配限制见[发布状态](../contributing/sdk-board.md)。 |

需要麦克风的录音或识别可能暂停已有媒体。暂停后可按应用提示恢复；文件或存储失效时播放停止并提示。

## 笔记

笔记库在 TF 卡的 `Notes` 目录。打开笔记前插入 TF 卡；程序可以安装在内部存储。

| 功能 | 操作步骤 | 结果 |
| --- | --- | --- |
| 新建与保存 | 点击底部新建，输入标题和正文，停止输入稍候。 | 后台保存；退出重开保留正文。 |
| 编辑 | 点击正文，输入中文、英文、换行；点击键盘收起。 | 已提交文字保留，光标位置的编辑只影响对应内容。 |
| 格式 | 选择文字或段落，通过格式面板使用粗体、斜体、标题、引用等选项。 | 所选内容改变格式。 |
| 段落与撤销 | 在更多操作中调整段落类型、移动或删除；使用撤销、重做。 | 正文按操作变化，可恢复最近编辑。 |
| 图片附件 | 添加 PNG/JPEG 图片并打开附件预览。 | 图片作为内容块保存在笔记库。 |
| 待办 | 添加待办并勾选；从待办汇总页打开原笔记。 | 汇总与正文的完成状态一致。 |
| 笔记本 | 打开笔记本列表，新建、选择、重命名或删除笔记本。 | 选中名称进入选中态，只显示该分类的笔记。 |
| 移动和多选 | 选择一篇或多篇笔记，移动到目标笔记本。 | 原分类移除，目标分类出现。 |
| 搜索与排序 | 输入搜索词；选择更新时间、创建时间或标题排序，切换列表/网格。 | 返回匹配内容并使用所选显示方式；未搜索时不显示多余结果说明。 |
| 回收站 | 删除笔记后进入回收站，选择恢复或永久删除并确认。 | 恢复后回到正常笔记；永久删除移除记录。 |
| 录音 | 在主页点击麦克风新建录音笔记，或在编辑页录入当前笔记；按需暂停、继续、停止。 | 录音可在离开页面或锁屏后继续；正在录音时不能转到另一笔记编辑。 |
| 录音回放 | 打开录音，播放、暂停、前后跳转十秒，添加或选择标记。 | 播放位置和标记对应。 |
| 转写 | 配置语音识别服务后，对录音发起转写。 | 转写文字单独保存，原录音保留。 |
| AI 整理 | 配置并授权 AI，选择改写、摘要、待办或会议纪要等方式，查看预览后应用。 | 确认后更新内容；正文已变化时不会无提示覆盖新编辑。 |
| 导入 | 选择 UTF-8 TXT、Markdown 或笔记备份 ZIP。 | 生成新的笔记副本。 |
| 导出 | 选择 TXT、带附件的 Markdown ZIP 或完整备份 ZIP。 | 文件写入 `Notes/Exports`。 |

录音当前为 16 kHz、16 位单声道 WAV，最长一小时。笔记正文及转写文字有容量上限，接近上限时根据页面提示拆分笔记。导入 Markdown 的外部图片链接保留为文本，不自动从网络下载附件。详细格式见笔记组件说明（源码：`modules/notes/README.md`）。

## 单词

在单词设置中选择学习范围和每日新词数量，再点击开始学习。查看答案后选择重来、困难、记住或熟练，进入下一张学习卡。时间异常时先修正系统时间，再继续基于日期的复习。

查词页输入单词，打开完整词条查看音标、释义、例句、词形等已有内容。可将单词加入生词本，或从生词本移除；暂停学习的词条可以恢复。词库由安装包提供，词库缺失或不兼容时页面给出错误。
