# 网络、音频与在线服务

平台分别管理网络连接、默认上行链路、音频输出和在线业务。某一服务失败只改变对应服务的状态；已连接蓝牙不要求 PAN 网络共享成功，获得 IP 地址也不证明互联网或目标服务可用。

## 默认网络选择

网络线程读取已注册接口的状态，按 WLAN STA、蓝牙 PAN 的顺序选择满足条件的上行。两者同时就绪时使用 WLAN；WLAN 不可用且 PAN 已就绪时使用 PAN。没有可用上行时报告离线，选择路由本身不发起 PAN 重连。

就绪条件包括接口启动、链路正常、有效 IPv4 地址和网关；PAN 额外要求网络 Profile 已连接。切换时在 TCP/IP 线程更新默认网卡和对应 DNS，增加状态版本 `generation`。在途请求看到版本变化后处理旧连接，后续请求使用新路由。

手机拒绝 PAN 时结束本次 PAN 尝试，保留仍正常的基础蓝牙连接。界面用普通蓝牙连接状态表示设备关系，不要求所有设备显示网络共享状态。用户重新发起连接时才建立新一轮连接意图。

热点用于设备网页访问，AP 地址为 `192.168.169.1`，不作为默认互联网出口，也不提供 NAT 转发。热点与 STA 的支持关系由当前 WLAN 能力决定。接口细节见[网络服务](../services/wifi.md)。

## 服务请求与失败处理

| 服务 | 请求触发与结果 | 重试或恢复边界 |
| --- | --- | --- |
| 网络校时 | 自动时间开启、网络就绪后由独立校时任务执行，更新系统时间。 | 沿用校时策略；路由切换和休眠通过该任务的状态处理，不用天气成功推断校时成功。 |
| 天气 | 分别更新实时天气、预报和空气质量，保留各项有效结果。 | 明确账号、权限错误等待配置变化；限流按服务要求处理；临时失败按有限策略恢复。缓存信息显示自己的更新时间。 |
| AI | 平台持有服务、模型与授权，应用提交会话并消费增量结果。 | POST 不自动重发或换服务。失败保留已经显示的文字和用户输入，具体诊断进入日志。 |
| 语音识别 | 录音与识别任务根据各自能力启动，返回识别文字。 | 识别不可用不直接禁止独立的朗读能力。取消后停止对应上传和会话。 |
| 语音朗读 | 文字分段合成并进入音频输出缓存。 | 暂停保留已合成数据；停止释放会话。供应商已经接受的内容不盲目重试。 |
| 网页服务 | 网络接口和账号库可用后提供设备管理。 | 已确定的账号库错误保持错误状态，修复后再启动，不靠每隔几秒重启解决。 |

AI 流式接收使用增量文本和结构化消息状态，完成或确需完整结果时才序列化；文字容量仍有上限。详细接口见 [AI 服务](../services/ai-services.md)、[语音服务](../services/speech-services.md)与 [HTTPS 客户端](../development/http-client.md)。

## 音频数据流

| 阶段 | 责任模块 | 输出 |
| --- | --- | --- |
| 内容供给 | 音乐、朗读、提示音、录音应用 | 压缩音频或 PCM、播放控制及当前业务状态。 |
| 解码和格式准备 | 对应解码组件、平台 PCM 输出封装与 SDK | 适合后续音频路径的数据。ACPU 组件按构建清单选择。 |
| 输出选择 | 平台与 SDK 音频服务 | 扬声器或已选蓝牙输出。判断输出设备与判断是否重采样分别进行。 |
| 重采样与软件混音 | 开启相应配置的 SDK 音频服务 | 将多个客户端转换到输出格式、应用各自音量并混合。 |
| 硬件播放 | DAC、音频 DMA 或蓝牙媒体链路 | 实际声音；已接收字节仍可能处于缓存，暂停和结束需考虑在途音频。 |

`epd_pcm_output_write()` 可能只接受部分数据，返回零表示暂时没有容量。调用方保留未接受部分，等待后继续，不在界面线程忙等。缓存时长是估计值，不包含尚未提交到 SDK 的数据。

录音由平台协调输入设备和媒体占用。笔记录音可以在离开编辑页或锁屏后继续，实际活动通过服务保持阻止不适合录音的系统休眠。录音结束是否恢复之前的音乐由产品交互决定，不能在销毁页面时直接启动其他应用的媒体。

## SDK 音频补丁与平台适配

当前送审修复限定在开启软件混音时生效，修正增益、缓存格式计算、通道合成及边界处理。关闭混音时已做预处理结果一致性检查。公开函数签名保持兼容，但恢复通用音量语义后，项目仍需要检查所有蓝牙播放路径是否正确调用 TWS 音量接口。

平台蓝牙音量适配尚未完成验证，具体补丁版本及验证范围见[SDK 与板级适配](../contributing/sdk-board.md)。

实现入口：源码：`src/services/net/network.c`、网络服务目录（源码：`src/services/net/`）、PCM 公共组件（源码：`modules/common/`）、SDK 音频服务（源码：`SiFli-SDK/middleware/audio/audio_manager/audio_server.c`）。
