# 笔记

`notes` 是平台原生动态应用。应用可以安装到内部存储，笔记正文、图片、录音、转写和恢复版本保存在 TF 卡的 `/Notes` 目录。

## 使用

| 功能 | 操作与结果 |
| --- | --- |
| 新建与编辑 | 首页点击底部“＋”新建笔记；点击已有笔记的正文即可编辑。整篇笔记连续显示，收起键盘保留已输入内容。停止输入约一秒后在后台保存。 |
| 文字格式 | 编辑时长按并拖动选择文字，点击工具栏“T”，再点击 B 或 I。阅读和编辑都显示同一段内的混合粗体、斜体，输入新文字会替换当前选区。 |
| 段落 | “T”面板可将当前段落改为正文、标题或引用；面板右上角“更多”提供段落移动、删除及其他类型。工具栏中的清单和附件按钮用于追加待办、正文、分隔线或图片。 |
| 撤销与重做 | 编辑工具栏提供撤销和重做。相近的连续输入合并为一组，历史保留在当前打开的笔记会话内。 |
| 图片 | 编辑工具栏点击附件按钮，再选择“图片”，从 TF 卡选取 PNG/JPEG，复制到笔记附件目录；点击图片内容块后选择“查看图片”。 |
| 待办 | 首页右上角的清单按钮汇总所有未删除笔记中的待办，并按来源笔记分组。勾选会修改原笔记；点击文字打开来源，“已完成”分组可以收起。待办页“＋”将新项目添加到“随手待办”，并进入新项目的编辑位置。 |
| 笔记本 | 首页文件夹按钮打开分类抽屉，显示全部、未分类、自建笔记本、最近删除和各分类数量。抽屉上方“＋”新建分类，选中的自建分类提供重命名和删除入口。 |
| 搜索与排序 | 搜索标题、正文、清单和转写。更多菜单可切换列表/网格，以及更新时间、创建时间、标题和升降序；视图与排序保存在 TF 卡。 |
| 批量操作 | 更多菜单进入多选，选中笔记后可批量移动、导出或移到回收站。 |
| 回收站 | 删除的正文与附件保留。打开回收站中的笔记可以恢复；永久删除需要确认。 |
| 本地录音 | 首页底部麦克风按钮新建录音笔记，编辑工具栏的麦克风按钮将声音归入当前笔记。开始前暂停已有媒体；结束后由用户手动恢复原播放。 |
| 录音控制 | 下方提供暂停、继续、标记和结束。返回桌面或锁屏后可继续录音。正在录音或处于暂停录音会话时，切换其他笔记的操作暂不开放；可以继续编辑当前笔记。 |
| 回放与标记 | 点击录音内容块进入菜单，可播放、前后跳转十秒、重命名录音、查看和改名标记。点击标记从相应位置播放。 |
| 转写 | 在录音菜单点击“转写 / 继续转写”。复用平台语音配置，分段保存结果；失败或取消后保留已完成段落，再次点击从尚未完成的位置继续。原始转写与修改后的正文分开保存。 |
| AI 整理 | 从笔记或段落菜单打开 AI 整理，再选择清楚自然、简洁、正式、仅改错字、摘要、待办或会议纪要。平台 AI 服务配置完成后，点击“授权服务”即可授权默认可用的文字服务；成功后显示灰色的“已授权服务”。整篇文字一次提交，超出服务容量时提示错误。 |
| 采用 AI 结果 | 结果先预览，“查看原文”显示提交时的正文；待办可逐项选择。润色保留段落与局部加粗、斜体。正文在请求后发生变化时不覆盖新内容。采用前保存恢复版本，“更多 → 恢复 AI 修改前的版本”可以还原。 |
| 导入 | 首页底部附件按钮选择 UTF-8 TXT、Markdown 文本或本应用导出的完整笔记 ZIP。导入 ZIP 会创建新副本。Markdown 导入保留支持的文字格式，外部附件链接保留为文字。 |
| 导出 | TXT 导出纯文字；Markdown ZIP 包含正文和附件；完整笔记 ZIP 保留内容块、样式、清单、图片、录音、标记及原始转写。导出文件位于 `/Notes/Exports`。 |

录音使用 16 kHz、16 bit 单声道 WAV，约 1.92 MB/分钟，单段上限一小时。录音和回放计时以五秒为常规刷新间隔，暂停和结束立即更新。文件转写通过现有实时语音服务发送录音数据，处理时长通常接近录音时长。

单篇笔记的文字及原始转写合计上限 256 KiB，最多 1024 个内容块；完整正文记录上限 1 MiB。每段录音最多 256 个标记。图片和音频文件独立存储，不计入正文大小。撤销、重做各保留最多 12 组，并按内存预算淘汰较早记录。

## 保存与恢复

正文采用临时文件、同步和替换机制，附带内容校验。列表摘要可以从正文重建。录音每两秒提交 WAV 头部及文件同步，暂停时排空采集缓冲并关闭文件；重新打开笔记时按实际文件长度修复录音时长。

拔卡后的新编辑暂留内存并显示未保存。重新插卡后刷新或再次保存，会核对磁盘上的笔记是否与上次成功保存的版本完全一致；一致时继续保存，不一致时保留当前内存内容并报告冲突。内存中的修改不能跨断电保留。

## 构建与安装

应用需要配套固件提供 `epd_record_*` 录音和文件转写接口，`epd_ai_authorize_service`、`epd_ai_authorization_poll` 授权接口，以及 LVGL 文字选择接口。先构建固件，再使用同一份 `app-profile.json` 编译和打包应用。

在仓库根目录的 PowerShell 中：

```powershell
. .\SiFli-SDK\export.ps1
scons -C project --board=sf32lb57-epd-gyd7n6_hcpu --board_search_path="$PWD/boards" APPS=notes -j8
```

安装包生成在 `project/build_sf32lb57-epd-gyd7n6_hcpu/app-packages/notes.sap`，包含应用模块和独立图标。

更新配套固件后，将 `notes.sap` 复制到 TF 卡，通过设备“应用管理 → 应用安装”安装到内部存储。运行数据仍保存在 TF 卡。

## 源码

- `notes_model.c`：内容块、文字样式、编辑历史所用序列化和 Markdown。
- `notes_store.c`、`notes_archive.c`：TF 卡保存、摘要、附件、ZIP 导入导出。
- `notes_runtime.c`：后台文件操作、录音、转写和 AI 请求。
- `notes_ui.c`、`notes_design.inc`：卡片和列表、分类抽屉、待办、录音与 AI 预览。
- `notes_composer.c`：连续正文排版、混合文字样式、选区、光标和平台输入法衔接。
- `src/services/speech/speech_record.c`：平台持续录音和文件转写适配。
- `tests/notes`：正文、存储归档、录音接口的主机回归检查。
