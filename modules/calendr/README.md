# 日历动态应用

`calendr` 是 SiFli EPD Platform 的离线日历应用，通过项目通用构建器生成 `calendr.sap`。应用入口、键盘、文件选择、字体缩放、输入组和后台任务均使用平台接口。

## 页面与交互

- 年视图以六个月为一页，月视图提供日期网格与当天安排，周视图显示一周事项，日视图显示当天安排和近期纪念事项。
- 支持普通日程、生日、纪念日和倒数日，以及编辑、复制、删除、搜索、日期跳转和日期推算。
- 开始与结束的日期、时间分别显示为按钮。日期按钮在卡片内展开月历；月份标题可切换为年月滑轮。时间按钮展开三行滑轮，中央数字使用较大字号和黑色，上下数字使用较小字号和灰色。时间遵循系统 12／24 小时设置。
- 日期及时间选择共用 `src/platform/epd_date_picker.h`，平台设置的手动校时页面使用同一组件。系统校时仅在保存时调用既有的 `system_time_set_local()`。
- 编辑内容在页面暂停和平台保存屏障中提交草稿；返回编辑页时保留输入。保存、导入、导出失败不会覆盖已经确认的数据。

## 模块职责

| 文件 | 职责 |
| --- | --- |
| `calendar_ui.c` | 页面、编辑状态、键盘与选择器、模块入口 |
| `calendar_model.c/.h` | 事项、重复例外、查询、检索、序列化 |
| `calendar_runtime.c/.h` | 后台读写、命令接收、只读快照、三个月的日期占用缓存 |
| `calendar_store.c/.h` | 应用记录与编辑草稿的一致编码 |
| `calendar_exchange.c/.h` | 应用备份和限定 ICS 子集 |

纯日期运算由平台 `epd_calendar.h` 提供。农历表来源和 MIT 许可保存在 `src/platform/epd_calendar.LICENSE`。公历范围为 1901—2099 年，农历只在表覆盖范围内显示；节气数据目前覆盖 2026 年。年度法定休／班数据尚未接入，不显示推测的休／班标志。

## 保存与提醒

日程、显示偏好、草稿、提醒规则和提醒进度统一保存在内部存储 `/flash/system/reminders/calendr.bin`。平台以带校验的原子替换提交，避免日程修改成功而提醒仍使用旧规则。应用安装在 TF 卡时，日程数据仍保留在内部存储。

`epd_reminder_commit()` 与 `epd_reminder_load()` 仅供后台服务调用。常驻提醒服务持有独立规则，不保存动态模块函数地址。最近一次提醒通过 SDK 闹钟调度；重复规则由常驻服务继续推进。通知写入通知中心，锁屏不弹框、不播放提示音，不主动恢复网络。卸载停用提醒并保留日程数据，重装后重新启用。

应用上限为 1,000 条事项，标题 80 个字符、地点 120 个字符、备注 2,000 个字符，同时受 UTF-8 字节容量约束。当前使用整份记录加载和原子快照，单份编码上限 2 MiB；内存不足会拒绝本次操作并保留旧数据。此实现未提供逐事项损坏隔离和长备注按需加载。

## 重复和交换格式

支持每天、每周指定星期、每月同日、每年同日及结束日期。重复事项可只修改／删除本次，或作用于整个系列，每个系列最多 32 个例外。月重复跳过不存在的日号；闰日生日在平年使用二月末。农历闰月不存在时采用同名普通月，农历三十遇小月采用月末。

- `.calbak` 保留事项、农历与重复例外。导入按稳定 UID 合并，保留当前显示偏好。
- `.ics` 支持公历日期、UTC 时间、全天／跨日、UTF-8 转义与折行、UID、标题、地点、备注、每日／每周／每月／每年规则、UNTIL、每周 BYDAY、EXDATE 和 DISPLAY 提醒。
- 地区 TZID／夏令时、COUNT、复杂 RRULE、RECURRENCE-ID 等未支持形式拒绝导入。农历及特殊月末规则使用 `.calbak`，不将其近似转换为 ICS。
- 导入前显示新增和重复条数，可选择更新重复项或仅导入新事项。
- 默认导出到 `/flash/data/calendr/Exports`，选择 TF 卡后导出到 `/sdcard/Exports`。文件读写遵守平台存储交接锁，解析与合并在锁外执行。

## 构建

在项目根目录执行：

```powershell
. ./SiFli-SDK/export.ps1
scons -C project --board=sf32lb57-epd-gyd7n6_hcpu --board_search_path=D:/program/LV_EpdReder/boards APPS=calendr -j8
```

安装包位于 `project/build_sf32lb57-epd-gyd7n6_hcpu/app-packages/calendr.sap`。应用使用新增的日期选择和常驻提醒接口，需要同次构建的匹配固件。`APPS=all` 已包含日历；预装仍由项目预装配置决定。

## 验证

`tests/calendar` 覆盖日期和农历范围、重复规则、序列化、导入导出、后台保存失败、草稿恢复、通知去重和存储锁边界。`tests/calendar/ui` 使用实际 LVGL 页面和共用选择器代码，检查返回、输入保存、月历选择、滑轮拖动、闰日、12 小时转换、手动校时保存及缩放，并生成页面图像。

主机图像未包含设备状态栏和实际墨水屏刷新。休眠中的 RTC 提醒、设备键盘、硬件返回键、TF 卡交接以及实际刷新耗时需要实机验收。
